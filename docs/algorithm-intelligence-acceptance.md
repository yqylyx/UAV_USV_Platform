# 算法仿真智能决策验收

## 场景矩阵

- 围捕：3+3/1 目标、10+10/2 目标、18+18/3 目标。
- 护航：3+3/1 敌船、10+10/2 敌船、12+12/2 敌船。
- 固定随机种子重复运行至少 3 次；另选 3 个随机种子检查泛化。

## 行为验收

1. 多目标任务的每个目标始终保持规划的 UAV/USV 精确配额。例如 18+18/3 必须始终为每组 6 UAV + 6 USV，设备身份可动态交换，但总数、类型数和设备唯一性不可变化。
2. 动态换组仅在预测截击时间明显改善、目标威胁升级或成员持续停滞时发生。稳定闭环确认期间不得换组；连续帧不得来回抖动。
3. 敌船在实际执行环未闭合前保持巡航或缺口突破速度，船头应朝可用缺口或安全侧翼转向。只有全局避障后的真实闭环持续成立，才允许受控减速和捕获。
4. 护航敌船接近拦截艇时，应预测最近会遇距离并主动改变航向；拦截艇保持阻断走廊，不应由友方单方面持续让路。
5. 目标卡必须同步展示意图与置信度、当前/最大速度、航向与方位、移动距离、缺口方向、最近拦截设备及动态换组原因。
6. 结束条件必须来自全局执行后的位置：任一目标存在超阈值缺口、目标不在包围多边形内或成员未到位时，任务不能进入 100%。

## 视觉与分辨率矩阵

逐档检查 1280×720、1366×768、1440×900、1536×864、1600×900、1920×1080、2048×1152、2560×1080、2560×1440、3440×1440、3840×2160。

每档都执行普通画面、左右栏分别折叠/恢复、双栏折叠、WebGL 放大和退出放大。验收标准：

- 所有活动设备均完整处于画面安全区内，不被边缘裁切。
- 小模型至少有可辨识的类型色标和航向短矢量；标记不改变模型比例、碰撞体或算法坐标。
- 目标、UAV、USV 在普通画面无需放大即可区分；高分辨率下标记不会等比例膨胀遮住编队。
- Resize 后 2 秒内恢复正确画幅，不黑屏、不重复加载场景、不丢失算法消息。
- 目标卡在 720p 下可滚动阅读，在 1080p 及以上不遮挡 WebGL 主画面。

## 自动化命令

在 `algorithm-service` 运行：

```powershell
python -m unittest discover -s tests
```

在 `frontend` 运行：

```powershell
npm run build
```

Unity 视觉项需要使用 Unity Editor 或最终 WebGL 构建做矩阵验收；仅通过前端构建不能替代运行时画幅检查。
