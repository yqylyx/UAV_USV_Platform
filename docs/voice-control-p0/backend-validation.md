## 关键覆盖

- 未登录、CSRF、非 ADMIN、跨用户与数据库角色撤销。
- 闭合请求结构、重复 JSON 键、16 KiB 上限和媒体类型。
- 黄金哈希、提案到期边界、上下文变更、普通帧不使计划失效。
- 12 路并发确认只创建一条 execution/outbox，确认与取消只有一方生效。
- 事务失败回滚，不留下半条执行链。
- worker 发送前复检角色，排队过期零写入且不消费命令序号。
- HTTP 受理、普通帧与心跳状态不构成命令成功证据。
- 重复/冲突回执、错误成员集合、旧代次回执隔离。
- 超时未知仍占槽；迟到成功保留 timedOutAt；最多三次只读查询且不重发动作。
- 发送异常的不确定窗口、后端恢复不重放。
- 关闭功能拒绝新写请求，已受理命令仍可处理与核对。
- 展示证据过期、重放不续期、绑定替换使旧报告失效。
- 有界行读取和连续非法封装处理。

## 环境与副作用

- Java：JDK 21；源码目标 Java 17。
- 数据库：H2 MySQL 模式及本机 MySQL 8.0.31。
- 测试使用随机命名的 `uav_usv_p0_test_<32位十六进制>` 数据库，结束后删除本次创建的库。
- 没有在正在使用的开发库运行 V19，没有重启当前项目服务。
- 配置保持 `app.voicecontrol.enabled=false` 默认值；未将测试进程替换为项目算法服务。
- 控制台中出现既有 Mockito 动态代理、旧迁移 SQL 弃用提示及网关连接失败日志，不影响测试通过；这些日志不是硬件联调成功证据。
