# P1 D1 本地语音识别界面接入决议

本决议统一修正此前文档中“独立本地语音识别页面”与最终界面要求不一致的问题。

## 最终位置

- 本地语音识别固定接入算法仿真工作区 `/?workspace=simulation` 右侧“语音控制”页签。
- 组件位于运行状态说明之后、P0四个手工任务按钮之前，即界面标注区域。
- 不增加独立页面、侧边栏入口或另一套状态管理。旧`/asr`地址只重定向到算法仿真工作区。

## 功能边界

- 用户进入算法仿真工作区即可录音或选择MP3，不要求生成场景、启动算法实例或等待Unity就绪。
- 识别结果只显示并允许编辑，不生成提案、不创建execution、不调用Runner、不改变Unity画面。
- P0手工开始、暂停、继续、停止按钮继续使用原上下文和权限规则，与ASR结果相互独立。
- `VITE_VOICE_ASR_ONLY=true`只决定右侧面板显示本地ASR输入并隐藏旧意图解析输入，不创建额外导航。

## 验收入口

登录后进入 `http://localhost:<前端端口>/?workspace=simulation`，在右侧“语音控制”页签完成D01–D12。验收时可以不生成场景；D07和D12必须确认识别“停止任务”等文字后，proposal、execution和算法command新增数仍为0。
